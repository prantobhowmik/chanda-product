Donations and expenses are the two kinds of entry. Both save on your phone first, so you can record without a connection.

## Fields

| Field | Donation | Expense |
| --- | --- | --- |
| Amount | Required | Required |
| Name | Donor name, required | Title, required |
| Date | Required | Required |
| Payment method | Required: cash, bKash, Nagad or bank | Optional |
| Receiver | Optional | Optional |
| Payment reference | Optional | Not used |
| Notes | Not used | Optional |

## Dates

Dates cannot be in the future.

## Members and approvals

When a member submits a donation or expense, an admin approves or rejects it. See [Approvals](/docs/approvals).
